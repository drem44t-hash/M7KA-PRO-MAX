# عشيرة تيم

خريطة حية: نراقب عدد متابعين حسابك على تيك توك بشكل دوري، وأي زيادة في العدد تطلّع بوت جديد يظهر في الخريطة وينضم لإحدى القبائل.

## طريقة التشغيل

```bash
npm install
npm start
```

بعدها افتح المتصفح على:

```
http://localhost:8091
```

## طريقتين للتشغيل

1. **تتبع حقيقي**: في الشاشة الأولى حط يوزر حساب تيك توك (بدون @) واضغط "ابدأ التتبع". السيرفر يفحص عدد متابعين الحساب **كل 5 دقايق**، ولو لقى زيادة، يطلّع بوت جديد لكل متابع إضافي.
2. **وضع المحاكاة**: اضغط "جرّب وضع المحاكاة" وبعدين زر "+ متابع تجريبي" أسفل الشاشة، يولّد متابعين وهميين فورًا عشان تختبر الشكل والأداء.

## ملاحظات مهمة عن التتبع

- تيك توك ما يوفر API رسمي لعدد متابعين أي حساب، فالسيرفر يقرأ **صفحة البروفايل العامة** (`tiktok.com/@username`) ويستخرج عدد المتابعين من الداتا المدمجة بالصفحة. لو تيك توك غيّر بنية صفحته، هذا الجزء بالـ`server.js` (دالة `fetchFollowerCount`) يحتاج تحديث.
- أول فحص بعد الضغط على "ابدأ التتبع" يثبّت نقطة البداية فقط (ما يطلّع بوتات)، وبعدها أي زيادة تحسب من هذي النقطة.
- الفحص كل 5 دقايق يعني ما راح تشوف البوت يطلع لحظة المتابعة بالضبط، بس خلال دقايق قليلة كحد أقصى. تقدر تغيّر المدة من متغيّر `POLL_INTERVAL_MS` في أول `server.js`.
- الحسابات الخاصة (private) ما راح تقدر تقرأ عدد متابعينها.

## هيكل المشروع

```
azikeh-tribe/
├── server.js          # يفحص عدد المتابعين دوريًا ويبث الزيادة عبر Socket.io
├── package.json
└── public/
    ├── index.html
    ├── style.css
    └── app.js          # رسم الخريطة والقبائل والكاميرا (سحب/تكبير)
```

## تخصيص القبائل

عدد القبائل وألوانها وأسماءها موجودة في أول ملف `public/app.js` داخل مصفوفة `TRIBES` — تقدر تضيف أو تحذف قبائل، وتغيّر الألوان بصيغة hex.

## النشر على GitHub

```bash
git init
git add .
git commit -m "عشيرة تيم"
git remote add origin <رابط_الريبو_تبعك>
git push -u origin main
```

بعد الرفع، أي شخص يشغّل المشروع لازم يسوي `npm install` عنده لأن `node_modules/` غير مرفوعة (موجودة في `.gitignore`).

## استضافة حية (اختياري)

عشان تشغّلها بشكل دائم مو بس على جهازك، ترفعها على استضافة تدعم Node.js مع تشغيل مستمر بالخلفية (مثل Render أو Railway أو VPS عادي)، لأن الفحص الدوري كل 5 دقايق يحتاج سيرفر شغال باستمرار، مو استضافة ستاتيك.
